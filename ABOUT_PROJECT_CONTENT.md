## BhumiDorpon
BhumiDorpon is a land-change and hazard visualization demo focused on viewing and comparing areas affected by natural hazards.

## Hazard modules
The project covers these five hazard categories:
- River erosion
- Flood
- Landslide
- Char formation and erosion
- Coastal erosion and land formation

## Map comparison and controls
Where implemented in the current project:
- Before and After maps are displayed side by side for visual comparison.
- Light GIS and Satellite basemap choices allow the same selected area to be viewed with different map backgrounds.
- Zoom and pan controls support map inspection; the comparison maps are intended to stay geographically synchronized.
- Hazard layers, legends, filters, and the supporting information area help users interpret the selected map view.

## Other project views
Where implemented in the current project:
- The dashboard provides an overview of available project information.
- The owner map/page provides its existing map-related view.

## Data note
The demo uses mock/synthetic data where specified by the project. Do not describe the information as live, real-time, field-verified, or survey-accurate unless the current implementation explicitly supports that claim.
