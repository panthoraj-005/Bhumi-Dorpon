# Design Addendum — Settings Information Views

- Match the existing BhumiDorpon visual design; do not redesign the application.
- The Settings option contains exactly two entries: About Project and Team Information.
- Keep typography, spacing, colors, icons, page/dialog behavior, responsive layout, and navigation consistent with existing components.
- About Project should use concise headings and feature bullets; include only verified existing project capabilities and honest data limitations.
- Team Information should present the supplied team name, leader, member, and copyright clearly.
- Do not add decorative content, invented logos, extra team roles, extra links, or unrequested settings.
